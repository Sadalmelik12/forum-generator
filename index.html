输入内容与实时预览

编辑器负责输入，右侧预览面板实时反映每一次修改。

Block 1 · 帖子信息

标题始终显示；点击「展开更多」可编辑板块、发帖时间、浏览量、回复量，以及「文本块头部模板」。

变量含义
{title}帖子标题
{board} {time} {views} {replies}板块 / 发帖时间 / 浏览量 / 回复量

默认模板：{title} {board} {time}，下方带实时小预览。

Block 3 · 楼层内容编辑

  • 添加楼层：底部「+ 添加新楼层」按钮，或 Ctrl+Enter / 双击回车。
  • 删除 / 复制 / 移动：楼层卡片右上角操作按钮。
  • 楼层信息：展开后填写用户名、身份、IP 属地、时间，每个字段旁有独立的「显示」开关。
  • 眼睛图标 👁/👀：展开/收起该楼的用户设置面板；Block 3 标题栏「显示楼层信息」复选框可一键开合所有楼层面板（仅控制面板开合，不改变文本显示）。
  • 快速导入用户 / 保存当前用户 / 清除用户信息：在楼层信息面板内操作。
显示规则：楼层号始终显示；用户名、身份、IP、时间是否出现由各楼层的「显示」开关决定，与面板开合无关。

实时预览

  • 视觉模式：模拟论坛帖子视觉效果（楼层号、用户名徽章、IP 属地等），右上角「风格」下拉可在 13 套配色间切换。
  • 文本模式：与导出的纯文本一致。
  • 预览栏右上角提示文字（如「双击回车→下一楼 | Ctrl+回车→新建」）可点击切换键位模式。

编辑模板

Block 2 · 楼层模板：控制每一楼的头部、尾部信息行与楼层之间的分隔。标题栏「收起/展开」可折叠整个 Block 2。

头部模板

变量含义示例
{floor}楼层号（自动编号）1, 2, 3…
{username}用户名吃瓜群众
{identity}身份标识[楼主] [版主]
{ip}IP 属地北京
{time}楼层时间2026-08-10 12:00

默认模板：{floor}L {username} {identity} IP:{ip}，渲染效果：1L 吃瓜群众 [楼主] IP:北京。

注意：变量是否显示受楼层级「显示」开关控制。模板里写了 {username}，但该楼「显示用户名」开关未开，就不会出现在输出中。

尾部模板

使用与头部相同的变量，留空则不显示。例：---{floor}L--- → 每楼底部显示 ---1L---。

楼层分隔方式

选项效果
两行空行楼层之间空两行（默认）
一行空行楼层之间空一行
分隔线楼层之间显示一条分隔线
无分隔无额外分隔
自定义输入自定义文本，\n 表示换行

每项选择旁都有对应的小预览。

楼层导航

左侧导航栏用于快速定位与批量操作楼层，右上角漏斗图标提供条件筛选。

基本操作

  • 跳转：点击楼层卡片直接跳转到对应楼层。
  • 选择：勾选卡片上的复选框；顶部「全选 / 反选」作用于当前导航列表。
  • 收起：导航区右上角 ☰ 收起/展开导航，获得更大编辑空间。

批量编辑

选中 2 个及以上楼层后，底部弹出批量工具栏：导入用户 / 设置用户名 / 设置身份 / 显示开关 / 删除选中，一次应用到所有选中楼层。

筛选器

点击导航区右上角漏斗图标，在图标旁浮出筛选面板（不会挤占导航排版）：

  • 筛选变量：楼层范围、用户名称、用户身份、IP 地址、内容。
  • 运算符：文本变量为 包含 / 严格等于（默认包含）；楼层范围为 属于 / 不属于。
  • 取值：可从下拉选择该变量已有的全部值，也可自行输入。
  • 多条件组合：可添加多个条件，条件间用 与(AND) / 或(OR) / 非(NOT) 组合（从左到右求值）。
  • 应用 / 取消筛选：编辑条件不影响导航，点「应用」才提交并关闭面板；「取消筛选」清除已应用条件。
「空」的语义：选择「空」＝该字段无此信息：运算符「包含」→ 显示全部楼层；「严格等于」→ 仅显示该字段为空的楼层。

筛选生效后，导航列表只显示命中的楼层；此时勾选、全选/反选、批量编辑、跳转均只作用于可见列表。

导入与导出

工具栏「导入」「导出」两个下拉菜单覆盖全部内容进出方式。

导入

  • 导入文本：粘贴文本自动分割为楼层。分割模式：按空行 / 按每行；可勾选智能识别（标题、楼层头部、楼层尾部）；可替换现有楼层或追加。
  • 导入工程：导入 .json 工程文件，三种模式：仅信息 / 仅格式 / 全部导入（推荐）。工程含多个帖子时会弹出帖子选择器。

导出 · 文本

  • 导出为 TXT 文件：保存为 .txt 纯文本。
  • 复制到剪贴板 / 复制富文本：纯文本或带格式文本；工具栏另有独立「复制文本」按钮。

导出 · 图片

  • 导出文本图片…：完整设置弹窗（右侧实时预览）——
    • 模式：长图（宽度可选 280~1080 或自定义，高度自适应）/ 分页图（小红书 3:4、4:5、1:1 等比例，智能分页、楼层不截断）。
    • 风格：默认纯文本 / 秀米卡片式（背景色、卡片色、圆角、底部标签）。
    • 字体：字号 / 字体 / 行高 / 页边距 / 文字色 / 背景色。
    • 图片格式：PNG（无损）/ JPEG（可调质量）；导出范围：全部 / 自定义起止 / 仅选中楼层。
  • 导出视觉图片：选择配色主题与预设尺寸，导出的图片与右侧实时预览的视觉风格一致。

导出 · 工程

导出工程文件：保存 .json，包含全部内容、模板、用户档案与导出设置，可用于备份与迁移。

沉浸模式

点击工具栏「✎ 沉浸写作」进入：隐藏导航、预览、模板等所有非必要元素，仅保留标题与楼层正文，专注写作。

沉浸下可编辑的内容

  • 帖子标题（居中大字，仅此一项来自帖子信息）。
  • 每楼的用户名称（正文上方内联输入框）。
  • 每楼的文本内容。

不额外设置用户信息栏——用户名直接在每楼内联输入，回车即跳到正文。

楼层推进与焦点流

  • 双击回车 或 Ctrl+Enter 进入下一楼 / 新建楼层时，先聚焦该楼的用户名输入框。
  • 直接输入用户名后按 Enter → 确认并跳到正文文本框。
  • 也可以下拉选择已有用户名：点击输入框，或用方向键 ↓/↑ 浏览候选（候选 = 全楼已有用户名 + 已保存的用户档案）；回车确认后跳到正文。刚按过方向键时，回车先让浏览器填入所选值（不跳转），再按一次回车进入正文。

退出沉浸

点击工具栏「← 退出沉浸」按钮，或按 Esc。

用户信息管理

工具栏「用户信息」打开管理弹窗，集中管理可复用的用户档案。

档案操作

  • 新建：填写用户名、IP 属地、身份后保存。
  • 编辑 / 删除：修改或移除已有档案。
  • 应用：把档案应用到当前选中的楼层；楼层信息面板内也可用「快速导入用户」下拉直接选用。
  • 批量管理：勾选多个档案后可批量删除。

在楼层中使用

  • 快速导入用户：楼层信息面板顶部下拉选择已保存用户，一键填入用户名/IP/身份。
  • 保存当前用户：把当前楼层的用户信息存为档案，供其他楼层复用。
  • 清除用户信息：一键清空当前楼层用户信息并关闭显示开关。
存储说明：用户档案只保存在当前页面内存中，新开页面/刷新后为空（刻意避免跨页面同步）。如需保留，请用「导出工程文件」备份，之后「导入工程」恢复。
