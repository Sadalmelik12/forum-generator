# 论坛体生成器

论坛体生成器是一款可视化论坛帖子排版工具，像发帖一样完成文本排版，最终导出为纯文本或图片。整个工具是单个 HTML 文件，无需安装、打开即用。**本工具适用于 PC 端浏览器（推荐 Chrome / Edge），不适用于手机浏览器。**

**楼层管理**：支持自由添加、删除、复制、移动楼层；每楼可独立填写用户名、身份、IP 属地与时间，并通过「显示」开关精确控制哪些信息出现在输出中。左侧楼层导航支持点击跳转、勾选/全选/反选与批量编辑，还能按楼层范围、用户名、身份、IP 等条件组合筛选，快速定位目标楼层。

**模板定制**：帖子信息与楼层头部、尾部均采用模板变量（`{title}`、`{floor}`、`{username}`、`{identity}`、`{ip}`、`{time}` 等），可自由调整版式；楼层之间支持空行、分隔线或自定义分隔文本。

**实时预览**：右侧面板随编辑即时刷新，提供视觉模式（模拟论坛效果，内置 13 套配色）与文本模式两种视图。

**导入导出**：支持粘贴文本自动识别并分割为楼层，也可导入 `.json` 工程文件（内容与格式可分模式导入）；导出支持 TXT 文件、剪贴板、富文本、长图、小红书分页图、秀米卡片式图片及视觉风格图片，字体、配色、尺寸均可自定义。

**沉浸式写作**：一键隐藏全部干扰元素，仅保留标题、用户名与正文，通过双击回车或 Ctrl+回车在楼层间连续写作；常用用户信息可存为档案反复复用。

## 使用与部署

- 使用教程：打开工具后点击「使用教程」，或直接打开 `tutorial.html`
- 部署方式：GitHub Pages + 手动发布闸门（详细部署指南为本地私有文件，不随仓库公开）
