论坛体生成器 - 使用教程

像发帖一样排版文本 —— 一款可视化论坛帖子排版工具，支持楼层管理、模板自定义、文本与图片导出。

快速上手

核心用途：将一段段文字排版成论坛帖子的格式（带楼层号、用户名、IP 属地等），最终导出为文本或图片。

30 秒上手

1

在 Block 1 帖子信息 中输入帖子标题（如「今天天气真好」）

2

在 Block 3 楼层内容 的文本框中输入第一楼的内容

3

点击「+ 添加新楼层」或按 Ctrl+Enter / 双击回车新建或进入下一楼

4

在右侧预览面板查看效果（视觉 / 文本两种模式，可选配色风格）

5

点击工具栏「导出」下拉，选择导出文本 / 图片 / 工程文件

提示：新楼层默认没有用户名和身份信息，且各字段的「显示」开关默认关闭。填写信息后需开启对应开关，信息才会出现在输出中。

输入内容与实时预览

编辑器负责输入，右侧预览面板实时反映每一次修改。

帖子信息（Block 1）

标题始终显示；点击「展开更多」可编辑板块、发帖时间、浏览量、回复量，以及「文本块头部模板」。

变量含义示例
{title}帖子标题今天天气真好
{board}板块日常闲聊
{time}发帖时间2026-08-10 12:00
{views}浏览量1024
{replies}回复量56

文本块头部模板默认：{title} {board} {time}，下方带实时小预览。

楼层内容编辑（Block 3）

添加与删除楼层

  • 添加：底部「+ 添加新楼层」按钮，或 Ctrl+Enter / 双击回车（行为可在预览栏切换）
  • 删除 / 复制 / 移动：楼层卡片右上角操作按钮

楼层信息

  • 展开信息面板：填写用户名、身份、IP 属地、时间；每个字段旁有独立的「显示」开关。
  • 眼睛图标 👁/👀：展开/收起该楼的用户设置面板；Block 3 标题栏「显示楼层信息」复选框可一键开合所有楼层面板（仅控制面板开合，不改变文本显示）。
  • 快速导入用户：面板顶部下拉选择已保存用户，一键填入。
  • 保存当前用户：把当前楼层用户信息存为用户档案。
  • 清除用户信息：一键清空当前楼层用户信息并关闭显示开关。
显示规则：楼层号始终显示；用户名、身份、IP、时间是否出现由各楼层的「显示」开关决定，与面板是否展开无关。

实时预览

  • 视觉模式：模拟论坛帖子视觉效果（楼层号、用户名徽章、IP 属地等）；右上角「风格」下拉可在 13 套配色间切换（浅色/深色/暖色/论坛蓝/护眼/暗夜紫/薄荷绿/莫兰迪/赛博/复古/商务灰/粉色/淡紫色）。
  • 文本模式：显示纯文本输出，与导出的文本内容一致。
  • 预览栏右上角提示文字（如「双击回车→下一楼 | Ctrl+回车→新建」）可点击切换键位模式。

编辑模板

Block 2 · 楼层模板：控制每一楼的头部、尾部信息行与楼层之间的分隔方式。整个 Block 2 可通过标题栏「收起/展开」折叠。

头部模板

变量含义示例值
{floor}楼层号（自动编号）1, 2, 3…
{username}用户名吃瓜群众
{identity}身份标识[楼主] [版主]
{ip}IP 属地北京
{time}楼层时间2026-08-10 12:00

默认模板：{floor}L {username} {identity} IP:{ip}，渲染效果：1L 吃瓜群众 [楼主] IP:北京。

注意：变量是否显示受楼层级「显示」开关控制。模板里写了 {username}，但该楼「显示用户名」开关未开，就不会出现在输出中。

尾部模板

使用与头部相同的变量，留空则不显示。例：---{floor}L--- 会在每楼底部显示 ---1L---。

楼层分隔方式

选项效果
两行空行楼层之间空两行（默认）
一行空行楼层之间空一行
分隔线楼层之间显示一条分隔线
无分隔无额外分隔
自定义输入自定义分隔文本，\n 表示换行

每项选择旁都有对应的小预览。

楼层导航

左侧导航栏用于快速定位与批量操作楼层，右上角漏斗图标提供条件筛选。导航区可收起（☰）以获得更大编辑空间。

跳转、选择与批量编辑

  • 跳转：点击楼层卡片直接跳转到对应楼层。
  • 选择：勾选卡片上的复选框；顶部「全选 / 反选」作用于当前导航列表。

选中 2 个及以上楼层后，底部弹出批量工具栏：

功能说明
导入用户从下拉选择用户档案，批量应用到所有选中楼层
设置用户名 / 设置身份批量设置选中楼层的用户名 / 身份
显示开关批量切换「显示用户名」「显示身份」等开关
删除选中批量删除所有选中楼层

筛选器

点击导航区右上角漏斗图标，在图标旁浮出筛选面板（不挤占导航排版）：

  • 筛选变量：楼层范围、用户名称、用户身份、IP 地址、内容。
  • 运算符：文本变量为 包含 / 严格等于（默认包含）；楼层范围为 属于 / 不属于。
  • 取值：可从下拉选择该变量已有的全部值（用户名、身份、IP 等），也可自行输入。
  • 多条件组合：可「+ 添加条件」多个条件，条件间用 与(AND) / 或(OR) / 非(NOT) 组合（从左到右求值）。
  • 应用 / 取消筛选：编辑条件不影响导航，点「应用」才提交并关闭面板；「取消筛选」清除已应用条件。
「空」的语义：选择「空」＝该字段无此信息：运算符「包含」→ 显示全部楼层；「严格等于」→ 仅显示该字段为空的楼层。

筛选生效后，导航列表只显示命中的楼层；勾选、全选/反选、批量编辑、跳转均只作用于可见列表。

导入与导出

工具栏「导入」「导出」两个下拉菜单覆盖全部内容进出方式。

导入

导入文本

  • 分割模式：按空行分割（每个段落成为一楼，默认）/ 按每行分割。
  • 智能识别：自动解析标题、楼层头部（如 1L 用户名 [楼主] IP:北京）、楼层尾部。
  • 替换 vs 追加：勾选「替换现有楼层」（默认）则清空当前内容，否则在末尾追加。

导入工程

导入 .json 工程文件，三种模式：

模式说明
仅信息只导入内容（标题/楼层/用户档案），不覆盖模板与格式
仅格式只导入模板/分隔符/导出设置，不覆盖内容
全部导入推荐完整导入格式与信息
多帖子工程：工程文件含多个帖子时会弹出帖子选择器，选择要加载的帖子。

导出文本

  • 导出为 TXT 文件：保存为 .txt 纯文本。
  • 复制到剪贴板：复制纯文本。
  • 复制富文本：复制带格式的文本（均在「导出」下拉的文本分组中；工具栏另有独立「复制文本」按钮）。

导出图片

导出文本图片…

完整的设置弹窗（左侧参数，右侧实时预览）：

  • 模式：
    • 长图：单张连续图片，宽度可选（280 ~ 1080 预设或自定义），高度自适应，2x 缩放。
    • 分页图：小红书格式 3:4 (1080×1440) / 4:5 (1080×1350) / 1:1 (1080×1080)，智能分页。
  • 风格：默认纯文本 / 秀米卡片式（背景色、卡片色、圆角、底部标签）。
  • 字体：字号、字体（等线/系统/黑体/宋体/无衬线/等宽）、行高、页边距、文字色、背景色。
  • 图片格式：PNG（无损，默认）/ JPEG（更小，可调质量 50-100）。
  • 导出范围：全部 / 自定义起止楼层 / 仅选中楼层。
分页原理：测量每个楼层块高度 → 按页面可用高度智能分页 → 每页独立排版 → 精确填充到目标尺寸，楼层不会被截断。

导出视觉图片

选择配色主题（13 套）与预设尺寸后导出，导出的图片与右侧实时预览的视觉风格一致。

导出工程

保存 .json 文件，包含全部内容、模板、用户档案与导出设置，可用于备份与迁移。文件名格式：forum-project-{标题}-{时间戳}.json。

沉浸模式

点击工具栏「✎ 沉浸写作」进入：隐藏导航、预览、模板等所有非必要元素，仅保留标题与楼层正文，专注写作。

沉浸下可编辑的内容

  • 帖子标题（居中大字，仅此一项来自帖子信息）。
  • 每楼的用户名称（正文上方内联输入框）。
  • 每楼的文本内容。

不额外设置用户信息栏——用户名直接在每楼内联输入，回车即跳到正文。

楼层推进与焦点流

  • 双击回车 或 Ctrl+Enter 进入下一楼 / 新建楼层时，先聚焦该楼的用户名输入框。
  • 直接输入用户名后按 Enter → 确认并跳到正文文本框。
  • 也可以下拉选择已有用户名：点击输入框，或用方向键 ↓/↑ 浏览候选（候选 = 全楼已有用户名 + 已保存的用户档案）；回车确认后跳到正文。刚按过方向键时，回车先让浏览器填入所选值（不跳转），再按一次回车进入正文。

退出沉浸

  • 点击工具栏「← 退出沉浸」按钮
  • 按 Esc 键

用户信息管理

点击工具栏「用户信息」打开管理弹窗，集中管理可复用的用户档案。

档案操作

  • 新建：填写用户名、IP 属地、身份后保存。
  • 编辑 / 删除：修改或移除已有档案。
  • 应用：把档案应用到当前选中的楼层；楼层信息面板内也可用「快速导入用户」下拉直接选用。
  • 批量管理：勾选多个档案后可批量删除。

在楼层中使用

  • 快速导入用户：楼层信息面板顶部下拉选择已保存用户，一键填入用户名/IP/身份。
  • 保存当前用户：把当前楼层的用户信息存为档案，供其他楼层复用。
  • 清除用户信息：一键清空当前楼层用户信息并关闭显示开关。
存储说明：用户档案只保存在当前页面内存中，新开页面 / 刷新后为空（刻意避免页面间相互影响）。需要保留时请「导出工程文件」备份，之后「导入工程」恢复。

键盘快捷键

快捷键功能说明

常见问题 (FAQ)

Q：新建楼层后为什么看不到用户名 / IP？

A：新楼层默认无用户信息且各字段「显示」开关关闭。展开楼层信息面板填写用户名/IP/身份后，勾选对应的「显示」开关即可；或直接用「快速导入用户」一键带入已保存的档案。

Q：模板里写了 {username}，导出却没有？

A：模板变量受楼层级「显示」开关控制：该楼「显示用户名」开关未开，则 {username} 不渲染。楼层号始终显示，不受开关影响。

Q：实时预览和导出图片为什么不一样？

A：三者目标不同：右侧「实时预览」是编辑时的可视化效果（视觉模式）；「导出文本图片…」是纯文本排版（其弹窗内有独立预览，可调字体/风格/尺寸）；「导出视觉图片」导出的就是实时预览的视觉风格。按需选择即可。

Q：按回车没有新建楼层？

A：「双击回车」默认是进入下一楼（已是最后一楼时才新建）。点击预览栏右上角的提示文字可切换为「双击回车新建」模式。Ctrl+Enter 始终新建楼层。

Q：筛选器里的「空」怎么用？

A：「空」＝该字段无此信息。运算符「包含」+ 空 → 显示全部楼层；「严格等于」+ 空 → 仅显示该字段为空的楼层。点「取消筛选」可随时复位。

Q：为什么新开的页面没有上次保存的用户？

A：用户档案只保存在当前页面内存中，新开页面 / 刷新后为空（刻意设计，避免页面间相互影响）。需要保留时请「导出工程文件」，下次「导入工程」恢复。

Q：导出的图片文字太小 / 模糊？

A：在「导出文本图片…」中调大字号、行高，或选择更宽的预设（长图）并保持 2x 缩放导出；分页图按目标比例导出，单个超长楼层会独立成页。

Q：分页图里楼层会被截断吗？

A：不会。分页采用智能算法：测量每个楼层块高度 → 按页面可用高度分页 → 每页独立排版，楼层不会被截断，页面精确填充到目标尺寸。

Q：「清除」下拉里的几项有什么区别？

A：重置内容＝清空楼层与帖子信息；重置格式＝还原模板、导出与视觉风格；重置用户信息＝清空所有用户档案；一起重置＝以上全部还原。
